================================================================================
                            快速开始
================================================================================

1. 恢复 NuGet 包:
   dotnet restore

2. 创建并应用数据库迁移:
   dotnet ef migrations add InitialCreate
   dotnet ef database update

3. 运行应用:
   dotnet run

4. 访问应用:
   - 前台: https://localhost:5001
   - 后台: https://localhost:5001/Admin/AdminAccount/Login
   - 管理员账号: admin / admin123
