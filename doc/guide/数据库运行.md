**千万不要在 `Data` 目录下运行！**

你需要**在项目的“根目录”下运行**。

### 1. 哪里是“根目录”？

看你的第二张图，**包含 `TourismPlatform.csproj` 这个文件的文件夹**，就是根目录。
也就是你 VS Code 打开的这个最外层文件夹：`作业-WINDOWS.NET项目`。

### 2. 为什么要在这里运行？

`dotnet ef` 命令需要读取两个关键文件才能工作：

1. **`TourismPlatform.csproj`**：告诉工具你的项目用了哪些库。
2. **`appsettings.json`**：告诉工具数据库连接字符串在哪里（配置信息）。

如果你进到了 `Data` 文件夹里运行，工具找不到这两个文件，就会直接报错说“找不到项目”。

### 3. 正确的操作步骤

1. 在 VS Code 中，直接按下快捷键 **`Ctrl + ~`** （波浪号键，通常在 Esc 下面）打开终端。
2. 看一眼终端显示的路径，它应该类似于：
   `C:\...\作业-WINDOWS.NET项目>`
   *(只要路径结尾是你的项目文件夹名，而不是 ...\Data 就对了)*
3. 直接粘贴运行命令：
   ```bash
   dotnet ef migrations add InitialCreate
   ```

**运行结果：**
命令执行成功后，它会自动根据代码，帮你把迁移文件**生成到** `Data/Migrations` 文件夹里（它自己会找路，不需要你进去）。

### dotnet run


是的，**恭喜你！这代表你的项目已经成功运行起来了！** 🎉

终端显示的 `Now listening on: http://localhost:5000` 意味着你的网站服务器已经启动，并且正在监听 5000 端口等待访问。

现在你有两种主要方式来查看数据：

### 方法一：直接通过浏览器查看（最推荐，最直观）

这是检验“代码逻辑”和“页面展示”是否正常的最好方法。

1. 打开你的浏览器（Chrome, Edge 等）。
2. 在地址栏输入：`http://localhost:5000`
3. 你应该能看到你写的首页。
4. 点击导航栏上的 **“景点 (Attractions)”** 或 **“酒店 (Hotels)”** 等链接。
   * 如果之前你写了 `SeedData.cs`（种子数据）并在 `Program.cs` 里调用了它，你现在应该能看到页面上列出了一些测试数据。
   * 如果页面显示“没有数据”，你可以尝试注册一个账号，然后手动去添加几条数据测试一下（前提是你做了添加功能）。

---

### 方法二：查看数据库内部数据（用于调试）

如果你想看数据库表里到底存了什么（比如加密后的密码、外键关联等），或者页面报错了你想排查数据，可以使用专业的数据库工具。

根据你的项目配置，你使用的通常是  **SQL Server LocalDB** 。

#### 1. 使用 Visual Studio (VS) 自带工具

如果你装了 Visual Studio（紫色图标那个）：

1. 在菜单栏点击 **“视图 (View)”** ->  **“SQL Server 对象资源管理器 (SQL Server Object Explorer)”** 。
2. 展开 `SQL Server` -> `(localdb)\MSSQLLocalDB` -> `Databases`。
3. 你应该能找到一个类似 `TourismPlatform` 名字的数据库。
4. 展开 `Tables`，右键点击你想看的表（比如 `Users` 或 `Attractions`），选择  **“查看数据 (View Data)”** 。

#### 2. 使用 VS Code 查看 (如果你用的是 VS Code)

1. 点击左侧扩展商店，搜索并安装 **"SQL Server (mssql)"** 插件。
2. 安装完成后，侧边栏会多出一个 SQL Server 图标。
3. 点击  **"+" (Add Connection)** 。
4. 按照提示输入：
   * **Server Name** : `(localdb)\MSSQLLocalDB`
   * **Database Name** : (留空回车，先连服务器)
   * **Authentication** : Integrated (回车)
   * **Connection Name** : 随便起个名，比如 `MyLocalDB`
5. 连接成功后，展开节点，找到你的数据库，右键表名选择 **"Select Top 1000"** 即可看到数据。

#### 3. 确认数据库名称

如果你不知道数据库叫什么名字，请打开你的项目文件  **`appsettings.json`** ，找到 `ConnectionStrings` 部分，里面 `Database=` 后面的就是数据库名。
