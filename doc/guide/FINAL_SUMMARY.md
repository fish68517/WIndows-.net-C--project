## 🚀 快速开始

### 5 分钟快速启动

```bash
# 1. 恢复 NuGet 包
dotnet restore

# 2. 创建并应用数据库迁移
dotnet ef migrations add InitialCreate
dotnet ef database update

# 3. 运行应用
dotnet run
```
