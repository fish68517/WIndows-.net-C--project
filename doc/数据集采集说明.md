# 数据集采集说明

## 1. 需求中的数据集要求

`doc/需求.txt` 要求：

```text
使用公开数据集(如CAIDA、UNSW-NB15等)进行模型训练和验证。
```

本项目最终选择 UNSW-NB15 作为公开数据集。理由是：该数据集面向网络入侵检测，包含正常流量和攻击流量，并提供训练集、测试集和 `label` 标签，适合本程序进行训练、测试和指标评价。

## 2. 数据集来源

官方说明页面：

```text
https://research.unsw.edu.au/projects/unsw-nb15-dataset
```

官方页面说明：

1. UNSW-NB15 由 UNSW Canberra Cyber Range Lab 使用 IXIA PerfectStorm 生成。
2. 数据包含正常流量和 Fuzzers、Analysis、Backdoors、DoS、Exploits、Generic、Reconnaissance、Shellcode、Worms 等攻击类型。
3. 数据集包含训练集 `UNSW_NB15_training-set.csv` 和测试集 `UNSW_NB15_testing-set.csv`。
4. 官方说明中训练集为 175,341 条记录，测试集为 82,332 条记录。

当前环境中官方 SharePoint 下载入口需要登录，因此本项目从公开可访问的 Zenodo 镜像下载同名训练/测试文件：

```text
https://zenodo.org/records/3768048
```

同时下载了特征说明文件：

```text
https://huggingface.co/datasets/Mouwiya/UNSW-NB15
```

## 3. 当前项目是否已经采集公开数据集

结论：已经采集。

当前工程已下载并保存 UNSW-NB15 公开训练集和测试集，并生成了程序可直接读取的处理后 CSV。

说明：程序当前同时支持两种数据格式：

1. `data/processed/UNSW-NB15/` 和 `data/processed/UNSW-NB15-demo/`：带表头、逗号分隔的 CSV，推荐课堂演示和正式运行使用。
2. `data/raw/UNSW-NB15/`：原始下载文件，虽然扩展名是 `.csv`，但实际是无表头、制表符分隔的 TSV。程序已增加自动识别逻辑，可以直接加载该目录。

原始下载目录：

```text
data/raw/UNSW-NB15/
```

程序可读取的处理后目录：

```text
data/processed/UNSW-NB15/
```

GUI 默认快速演示目录：

```text
data/processed/UNSW-NB15-demo/
```

## 5. 程序使用的数据字段

当前 C 程序读取以下 16 个数值特征：

```text
dur, spkts, dpkts, sbytes, dbytes, rate, sttl, dttl,
sload, dload, sloss, dloss, sinpkt, dinpkt, sjit, djit
```

测试和检测阶段使用 `label` 字段进行结果评价：

```text
label = 0  正常流量
label = 1  异常流量
```

训练阶段只使用 `label=0` 的正常流量训练自编码器，使模型学习正常流量模式。

## 6. GUI 如何加载公开数据集

双击运行：

```text
build/network_anomaly_detector.exe
```

GUI 默认加载快速演示目录：

```text
data/processed/UNSW-NB15-demo/
```

如果要加载全量公开数据集：

1. 点击 GUI 中的 `选择数据目录`。
2. 选择目录：

```text
data/processed/UNSW-NB15/
```

3. 点击 `训练模型`。
4. 点击 `测试模型`。
5. 点击 `实时检测`。

如果选择原始下载目录：

```text
data/raw/UNSW-NB15/
```

程序会自动识别 raw UNSW-NB15 的无表头 TSV 格式，并按固定字段位置读取 16 个数值特征和 `label` 标签。由于 raw 目录未做训练/测试文件重新映射，课堂讲解和演示仍建议优先使用 `data/processed/UNSW-NB15/` 或 `data/processed/UNSW-NB15-demo/`。

如果所选目录中存在 `realtime_sample.csv`，实时检测优先使用该文件；否则使用 `UNSW_NB15_testing-set.csv` 模拟实时流量输入。

如果加载失败，可打开：

```text
output/app.log
```

查看程序识别到的是 `header CSV` 还是 `raw UNSW-NB15 TSV without header`。
