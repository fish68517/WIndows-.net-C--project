# 程序功能与操作说明

## 1. 程序是什么

本程序是一个“基于深度学习的网络异常流量检测系统”。

它的作用是：

1. 读取网络流量数据集。
2. 使用深度学习自编码器模型学习正常网络流量特征。
3. 对新的网络流量进行异常检测。
4. 当发现异常流量时输出报警。
5. 在 GUI 页面中展示检测结果和异常曲线图。

程序文件：

```text
build/network_anomaly_detector.exe
```

双击该 exe 即可打开图形界面。

## 2. 使用的数据集

本项目使用公开数据集 UNSW-NB15。

数据集来源：

```text
https://research.unsw.edu.au/projects/unsw-nb15-dataset
```

当前工程中已经采集并处理好的数据目录：

```text
data/processed/UNSW-NB15/
```

为了课堂演示更快，程序默认加载公开数据集演示子集：

```text
data/processed/UNSW-NB15-demo/
```

演示子集来自 UNSW-NB15，不是手工编造数据。

原始下载目录也已经保留：

```text
data/raw/UNSW-NB15/
```

该目录中的文件是无表头、制表符分隔格式，程序已经支持直接识别和加载。课堂展示时建议优先使用 `data/processed/UNSW-NB15-demo/`，因为速度最快；正式说明全量数据时建议使用 `data/processed/UNSW-NB15/`，因为该目录已经整理为标准 CSV。

## 3. 设计原理

本系统采用自编码器模型进行异常检测。

自编码器的基本思想：

1. 输入一条网络流量记录。
2. 模型先压缩特征，再尝试还原原始特征。
3. 如果是正常流量，模型容易还原，重构误差较小。
4. 如果是异常流量，模型不容易还原，重构误差较大。
5. 当重构误差超过阈值时，系统判定为异常并报警。

本项目选择自编码器的原因：

1. 适合使用 C 语言实现。
2. 不依赖 Python、TensorFlow、PyTorch 等大型框架。
3. 可以打包为 exe，方便复制到老师机器上运行。
4. 原理直观，便于课程设计讲解。

## 4. 主要功能

### 4.1 选择数据目录

功能：让用户通过打开目录的方式加载数据集。

程序要求目录中包含：

```text
UNSW_NB15_training-set.csv
UNSW_NB15_testing-set.csv
```

如果目录中还有：

```text
realtime_sample.csv
```

实时检测会优先使用该文件。

### 4.2 训练模型

目的：让模型学习正常网络流量的特征。

功能：

1. 读取训练集。
2. 只使用 `label=0` 的正常流量。
3. 对特征进行归一化。
4. 训练自编码器模型。
5. 保存模型文件和归一化参数。

输出文件：

```text
model/autoencoder_model.bin
model/normalize_params.txt
output/train_log.txt
```

### 4.3 测试模型

目的：验证模型检测异常流量的效果。

功能：

1. 读取测试集。
2. 加载训练好的模型。
3. 计算每条流量的重构误差。
4. 判断正常或异常。
5. 和 `label` 标签对比，计算评价指标。

输出指标：

```text
Accuracy
Precision
Recall
F1
```

输出文件：

```text
output/test_metrics.txt
output/detect_result.csv
output/alarm_log.txt
```

### 4.4 实时检测

目的：模拟网络流量实时进入系统，进行实时分析和报警。

功能：

1. 逐条读取流量记录。
2. 计算重构误差。
3. 超过阈值则报警。
4. 在 GUI 中显示曲线图。

曲线图含义：

```text
蓝线：每条流量的重构误差
红虚线：异常判断阈值
红点：被判定为异常的流量
```

输出文件：

```text
output/detect_result.csv
output/alarm_log.txt
```

## 5. 操作流程

### 5.1 快速演示流程

1. 双击：

```text
build/network_anomaly_detector.exe
```

2. 程序默认加载：

```text
data/processed/UNSW-NB15-demo/
```

3. 点击 `训练模型`。
4. 等待提示“训练完成”。
5. 点击 `测试模型`。
6. 查看 Accuracy、Precision、Recall、F1。
7. 点击 `实时检测`。
8. 查看下方曲线图和报警日志。

### 5.2 使用全量公开数据集

1. 双击打开 exe。
2. 点击 `选择数据目录`。
3. 选择：

```text
data/processed/UNSW-NB15/
```

4. 点击 `训练模型`。
5. 点击 `测试模型`。
6. 点击 `实时检测`。

说明：全量数据训练时间比演示子集更长，课堂展示建议优先使用 `UNSW-NB15-demo`。

### 5.3 使用原始下载数据目录

如果选择：

```text
data/raw/UNSW-NB15/
```

程序也可以执行训练、测试和实时检测。这个目录中的文件虽然后缀是 `.csv`，但实际不是普通逗号 CSV，而是无表头 TSV。程序会在后台自动识别字段位置，并在 `output/app.log` 中记录：

```text
csv format detected: raw UNSW-NB15 TSV without header
```

如果要给老师稳定演示，推荐仍使用 `data/processed/UNSW-NB15-demo/`；如果要说明“已经采集并能读取公开原始数据”，可以选择 `data/raw/UNSW-NB15/` 后运行一遍训练、测试、实时检测。

