# 端到端测试报告 - 匿名情绪日记应用

## 测试概述

本文档描述了为匿名情绪日记应用实现的端到端测试套件。测试覆盖了所有主要工作流程，包括用户注册、登录、日记创建、情绪分析、高风险检测和日志记录。

## 测试执行方式

### 方式 1：通过 TestRunner 独立运行
```bash
dotnet run --project AnonymousEmotionDiary/AnonymousEmotionDiary.csproj -- TestRunner
```

### 方式 2：在应用启动时运行测试
可以在 Program.cs 中添加测试执行逻辑，在应用启动时自动运行测试。

## 测试数据清理

测试完成后，测试创建的数据将保留在数据库中以供验证。如需清理测试数据，可以：

1. 删除 `AnonymousEmotionDiary.db` 文件
2. 删除 `Logs` 目录中的日志文件
3. 重新启动应用以重新初始化数据库
